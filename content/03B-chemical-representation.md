# 03B · 化学表示：模型究竟看见了什么？

## 这一节回答什么问题？

前面一直把输入写成 `x`：

```text
输入 x → 模型 → 预测的 logS
```

但一个分子结构图不能自动成为机器学习输入。人看到原子、键、官能团、构象和化学环境；模型接收的是字符串、数值向量、图或三维几何。这个转换过程叫**分子表示（representation）**或**特征化（featurization）**。

本节最重要的问题不是“哪种表示最先进”，而是：

> 这种表示保留了哪些信息、忽略了哪些信息，它是否适合当前科学问题？

## 听众最后必须记住的 3 件事

1. 分子必须先转换成机器可处理的表示。
2. 分子描述符、分子指纹、SMILES、分子图和 3D 表示保留与缺失的信息不同。
3. 表示选择取决于科学问题、数据质量和验证结果，不是越复杂越好。

## 讲述逻辑与时间

用一分钟承接“输入 → 模型 → 预测的 logS”；两分钟区分分子表示与模型；三分钟比较五类表示；一分钟说明任务驱动的选择；最后用两分钟自问自答，并自然交给 C 部分。

本节只解释“模型看见什么”和“怎样选择输入”，不展开消息传递、等变网络结构、发现工作流或智能体；这些属于 C 部分。

## 必须出现的关键视觉 2 / 2

**关键视觉 2：同一个分子的多种表示。**并排给出人类视图、分子描述符、SMILES、分子指纹、分子图和 3D 表示。每种表示只回答：`保留什么？缺少什么？常与什么模型搭配？`

## 核心小节 4：化学表示与任务驱动的选择

### 分子表示与模型不是一回事

同一种表示可以交给不同模型，同一种任务也可以使用不同表示：

```text
分子描述符       + 线性模型 / 树模型
Morgan 分子指纹 + 随机森林 / SVM / MLP
SMILES          + 序列模型 / Transformer
分子图           + 图神经网络（GNN）
3D 坐标         + 几何神经网络 / 等变神经网络
```

表示决定模型“能够看到什么”；模型决定怎样从这些信息中学习关系。不能仅凭模型名称判断方案是否适合化学问题。

---

### 五类常见表示

| 表示 | 模型实际接收什么？ | 主要保留什么？ | 需要警惕什么？ |
|---|---|---|---|
| 分子描述符 | 分子量、LogP、TPSA、氢键数等固定数值 | 预先定义的全局或局部物化特征 | 未计算的结构信息不会自动出现；描述符选择带入了人的假设 |
| 分子指纹 | 稀疏计数或位向量，例如 Morgan/ECFP | 一定半径内的局部原子环境和子结构模式 | 哈希位可能碰撞；通常不显式给出完整三维构象和远程几何关系 |
| SMILES | 按语法编码的字符串 | 原子、键、分支、环及可选立体化学等连接信息 | 同一分子可以有多个合法 SMILES；字符串本身不等于一个确定的三维构象 |
| 分子图 | 节点、边及其属性 | 原子、化学键和拓扑连接 | 普通 2D 图通常不包含特定构象；节点与边的特征仍需明确设计 |
| 3D 原子表示 | 元素种类、坐标、距离、角度或邻域 | 构象和空间局部环境 | 结果依赖构象质量与采样；还要正确处理旋转、平移、置换等对称性，成本通常更高 |

#### 容易误解的地方

分子指纹不是“每个位都唯一对应一个官能团”。在哈希 Morgan 分子指纹中，不同局部环境可能映射到同一个位；解释时应检查生成参数和位来源信息。

SMILES 是线性字符串，但分子不是“一维对象”；普通分子图不自动包含可靠构象；3D 信息更丰富，也会引入构象、采样、对称性和计算成本问题。

---

### 化学联系：表示选择取决于任务，而不是排行榜

仍以水溶解度预测为例：

- 小数据集上，物化描述符或分子指纹配合简单模型可能已经是很强的基线；
- 如果希望从连接关系中学习局部结构模式，可以尝试分子图；
- 如果目标强烈依赖构象、相互作用或原子空间环境，3D 信息可能更重要；
- 但如果输入的 3D 构象不可靠，复杂模型并不会自动修复错误信息。

因此应同时考虑：

```text
科学问题
数据量与数据质量
任务需要的化学或物理信息
不变性与对称性
可解释性
计算资源
```

表示越复杂，通常意味着更高的数据、计算和验证要求；复杂并不自动等于更可靠。

### 两分钟自问自答：这个 logS 任务应该选哪种表示？

#### 讲者抛出问题

> 我们只有 800 个带噪声的 `logS` 样本，希望预测包含新骨架的候选分子。应该直接选择基于 SMILES 的 Transformer、图神经网络（GNN）或最复杂的 3D 模型吗？

停顿几秒，然后明确回答：**不应该只凭“模型更先进”直接选择。**

#### 讲者回答

第一步看**任务需要什么信息**。水溶解度与分子大小、极性、氢键能力、疏水性和局部结构都有关，因此分子描述符和分子指纹已包含有用信息；如果希望模型进一步从连接关系中学习结构模式，可以比较分子图。

第二步看**数据是否支撑模型复杂度**。800 个带噪声样本通常不足以仅凭数据训练一个很大的序列或 3D 模型。基于 SMILES 的 Transformer 可能依赖预训练和规范的数据处理；图神经网络也需要与简单基线公平比较，而不是默认一定更好。

第三步看**3D 信息是否必要且可靠**。如果目标是构象相关能量、空间相互作用或立体选择性，2D 分子指纹可能缺少关键几何信息；但对当前 `logS` 任务，如果没有可靠构象与采样方案，加入 3D 坐标反而可能带来新的噪声。

因此合理起点是：

```text
分子描述符 / 分子指纹 + 简单模型 → 建立基线
分子图                           → 检查拓扑学习是否带来稳定提升
SMILES / 3D                      → 有足够数据、预训练或明确物理需求时再比较
```

所有表示必须使用同一套去重规则、骨架划分和评价指标比较，才能把性能差异主要归因于表示与模型，而不是数据划分。

#### 用一句话收束 03B

> **没有脱离任务的“最佳分子表示”；应选择包含必要化学信息、又与数据规模相匹配的最简单表示，再用可信评估验证。**

---

## 本节最后留下的三句话

1. **分子不会自动成为机器学习输入。**
2. **分子表示决定模型能够利用哪些化学信息。**
3. **选择包含任务所需信息的最简单表示，再用可信评估验证。**

B 部分到此完成“是否泛化”到“模型看见什么”的桥接；具体图模型、3D 模型、发现工作流和智能体交给 C 部分。
